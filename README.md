Car evaluation model

This project uses a decision tree classifier to predict car acceptability from features like buying price, maintenance, persons, boot size, and safety. The model aims to assign each car to one of four classes, unacc, acc, good, or vgood, based on the UCI car evaluation data set. The model achieved 95.66% test accuracy, but performance varied by class. For example unacc had an F1 score of 0.99, while good had only 0.74. The confusion matrix showed some acc cars were misclassified as good or unacc. A key limitation is class imbalance, with far more unacc cases than good. So high accuracy may hide weaker minority class performance. Ethically, the data set's criteria reflect fixed definitions of acceptability, which may not reflect all user values. So the model should inform, not replace human judgment.
